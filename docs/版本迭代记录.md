### V4.6.1（2026-08-04）— 稳定修复（React 端）

- `f326e162` **修复：V4.6.1 SSE 心跳保活 + 饼图空白圆环 + 图表质量约束（3 项）+ 遗留改动全量入库**
  - **SSE 心跳保活**：节点内非流式 LLM 调用（实测单步 40-75s）期间无任何事件推送，前端 45s 看门狗误判连接挂死而 abort（"分析超时（45 秒无响应）"）。后端新增 `_with_heartbeat` 每 20s 穿插 `{"type":"heartbeat"}` 事件（graph 结束/异常即终止，心跳从属于主数据流），前端忽略心跳仅重置看门狗；实测"整体经营状况分析"全链路 165-246s，修复前必超时，修复后最大静默 20s
  - **饼图空白圆环**：后端图表契约字段为 `x_data`（下划线），React 版 `extractCharts` 未归一化导致 `config.xData` 为 undefined → pie data 空 → ECharts 渲染灰色无数据占位环（#cccccc）。解析层修复（对齐原生版 `utils.js`），**历史报告自动恢复**，分享页共用管线同受益
  - **图表质量约束**：排名类必须 bar 禁止 pie（prompt 硬约束 + `_sanitize_charts` 输出硬校验，占比 pie 不误伤）、数据 TOP 10、多个数值列时优先业务金额列（销售额/收入/金额，避免选中订单数列）
  - **文档**：CHANGELOG.md 记录 V4.6.1 三项修复
  - **清理**：删除误入库的 `.playwright-mcp/` 调试快照（27 个文件）
  - ✅ 端到端验证（真实全链路）：修复前"各门店销售额排名"生成 pie 圆环（20 项/订单数）；修复后 bar 柱状图（TOP 10/销售额（元）），浏览器 canvas 像素验证 97% 单色柱渲染正常
