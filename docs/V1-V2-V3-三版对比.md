## Agent 体系对比

| 维度 | V1 | V2 | V3 |
|------|-----|-----|-----|
| **编排框架** | 手动 Python 函数调用 | LangGraph StateGraph | LangGraph StateGraph |
| **并行策略** | ❌ 顺序执行 | ✅ Send API 扇出 3 Agent | ✅ Send API 扇出 5 Agent |
| **领域 Agent** | 0（统一 Analyzer） | 3（Sales/CRM/Finance） | 5（+ Inventory/Supply Chain） |
| **智能路由** | ❌ 固定流程 | ✅ Supervisor LLM 决策 | ✅ Supervisor LLM 决策（5 选多） |
| **工具调用** | ❌ 硬编码 SQL 模板 | ✅ Function Calling (tool_choice) | ✅ Function Calling (tool_choice) |
| **质检机制** | ✅ 简单 Reflection | ✅ 4 维结构化质检 | ✅ 4 维质检 + 条件重试 |
| **错误隔离** | ❌ 一处失败全流程中断 | ✅ Agent 级 try/except 隔离 | ✅ Agent 级隔离 + 友好错误映射 |
| **上下文记忆** | ❌ 无 | ❌ 单轮 | ✅ 多轮对话（实体记忆+指代消解） |
| **Prompt 管理** | ❌ 代码内硬编码 | ❌ Python 常量 | ✅ YAML 外部化 + 热重载 |

## 产品决策演化

| 决策点 | V1 | V2 | V3 | 演化逻辑 |
|--------|-----|-----|-----|----------|
| **LLM 选型** | DeepSeek | DeepSeek | DeepSeek | 三版一致，性价比最高 |
| **Agent 架构** | 自研流水线 | LangGraph | LangGraph | V2 果断切换成熟框架，V3 复用 |
| **前端方案** | Streamlit | 原生 HTML | 原生 HTML + 拆分 | V2 抛弃 Streamlit 获得完全控制权 |
| **Embedding** | ❌ | Ollama BGE-M3 | Ollama BGE-M3 | V2 引入本地向量，零成本 |
| **质检** | 简单反思 | 结构化 4 维质检 | 同 V2 + 条件重试 | V2 定型，V3 微调 |
| **报告输出** | 统一格式 | 查询/分析双模式 | 同 V2 + 图表嵌入 | V2 核心创新，V3 增强 |
| **消息推送** | ❌ | n8n | n8n | V2 引入，V3 沿用 |
| **移动端** | ❌ | ❌ | 响应式 Web | V3 新增，覆盖老板手机场景 |
| **数据扩展** | 销售为主 | +CRM + 财务 | +库存 + 供应链 | 逐步覆盖全业务域 |
