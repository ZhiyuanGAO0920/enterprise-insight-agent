## 0. 一句话说明

**Enterprise Insight Agent（EIA）V5** 是一个面向连锁零售的 Multi-Agent AI 经营分析平台：用户用自然语言提问，系统在 60 秒内返回一份诊断报告（数据概览 + 根因诊断 + 可执行建议）。我（高志远）以**独立产品负责人**身份完成全部产品设计、架构决策与评估体系建设，代码全部自己写（借助 Claude Code 辅助）。

**项目核心用途**：求职作品集（AI 产品经理岗位）+ 面试实战素材 + 技术能力证明。这是"带真实数据、可演示、有测试和评估体系"的完整项目，不是 demo 玩具。

**V5 收官一句话**：从"会分析数据的 Multi-Agent"升级为 **"能够验证自己分析结果、可证明多租户安全、成本受控的 Enterprise Analytics Agent"**，已发布即冻结（之后仅做面试按需小修与素材同步）。

## 2. 系统架构

```
Supervisor（规划路由，temperature=0）
    ↓ LangGraph Send 并行扇出
[sales] [crm] [finance] [inventory] [supply_chain]  ← 5 领域 Agent
    ↓ 扇入
Aggregator（纯 Python 聚合，不耗 Token）
    ↓
Chart Advisor → Report Agent（SSE 流式输出）→ Reflection Agent（4 项质量契约质检，最多重试 1 次）
    ↓
Save Memory（pgvector 1024 维，BGE-M3 本地 Embedding）
```

- **11 个 Agent 节点**：supervisor（路由）、5 领域 Agent（sales/crm/finance/inventory/supply_chain）、aggregator、chart advisor、report agent、reflection agent、memory
- 编排：LangGraph StateGraph + Send 并行扇出/扇入（`app/workflow/graph.py`）
- 报告输出：SSE 流式（"打字机"效果）；双模式输出——查询型→表格+关键洞察，分析型→完整报告
- 质检：Reflection 4 项质量契约（Numerical 30% / Grounding 35% / Reasoning 15% / Alignment 20%），加权 ≥70 且 Numerical/Grounding ≥50 双门槛，重试 1 次（实测：0 次→25% 报告有问题；1 次→修复率 60%；2 次边际递减）
- 中间件栈：`请求 → CORS → 审计日志(Audit) → 多租户(Tenant) → API版本头 → 路由`（`app/middleware/`）

## 4. 核心产品决策（决策记录，面试可讲）

## 7. 评估体系与金丝雀闭环
