> **"让经营决策者用自然语言和 AI，从散落在 ERP/CRM/POS 里的企业数据中，直接拿懂、可用、可落地的经营洞察。"**

## 竞争格局总览

```
            SaaS 交付 ←─────────→ 自建部署 ←──────────────→ 通用 AI + 数据
         │                        │                        │
   ChatGPT + 通用 AI  │  【通用 AI + 数据】 │                   【SaaS BI】
   (需企业版插件)       │  (OpenAI Enterprise)       │  Tableau / Metabase / ThoughtSpot
                         │                        │                        │
         我们的 V4  │  ChatGPT + 数据 + 通用 AI |  数据分析专用 + SaaS BI | 工具型（单用户）
                         │   ↓                    │       ↓          │
    React 18 + TS + Ant Design 5 | 自然语言驱动 | 多源数据整合 | 拖拽式配置
         Docker 一键部署        | Agent 自动编排 | 人工拼接数据源  | 人工分析
         多租户 / 审计日志      | PDF 导出 / 企微通知  | 定制化 Dashboard
         离线 / 内网部署       | RAG 搜索 + 会话管理    | 人工总结
```

我们的定位：**SaaS 交付的专用 AI 分析平台**——而非通用 AI 工具的"插件化模板"。

## 直接竞品

### 1. 帆软 FineBI

| 维度 | 帆软 FineBI | 我们 |
|------|------------|------|
| **核心能力** | 拖拽式 BI 报表平台 | 自然语言驱动的 AI 分析 |
| **目标用户** | 数据分析师、BI 工程师 | 老板、区域经理、店长、总部高层 |
| **使用门槛** | 需要学拖拽操作、理解数据模型 | 零门槛，会中文打字就行 |
| **输出形式** | 可视化仪表板 | 中文分析报告 + ECharts 图表 + 行动建议 + PDF 导出 |
| **部署方式** | 私有化部署 | **Docker 一键部署**（开发/生产） |
| **价格** | 数万～数十万/年 | 远低于帆软（**单次性买断**，无订阅费） |
| **优势** | 成熟稳定、企业级功能完善 | 使用门槛低、分析深度强、一行代码完成部署 |
| **劣势** | 需要专人维护、学习成本高、无 AI 自动分析能力 | 需要熟悉 Durable / Linux 运维、动态能力弱（不支持 Agent 自动调用自己） |
| **V4 区别** | 帆软是工具型产品（用户用它干活），我们是 Agent 型产品（产品帮用户干活）——每天 5-10 次自动分析推送到群通知。 |

**面试回答模板**：
> "帆软是给数据分析师用的，需要培训和专人维护。我们的用户是老板。老板不想学拖拽，也不想养分析师。他只问'最近华东区怎么样'，1 分钟就拿到答案。我们是互补关系——他们把报表继续做，我们做日常经营分析决策。"

### 2. ChatGPT / 通用 AI + 企业数据

| 维度 | ChatGPT + 数据 | 我们 |
|------|---------------|------|
| **核心能力** | 通用 AI 对话 + 用户自己上传数据 | 聚直零售场景，预置行业知识 + 完整的链路编排 |
| **使用方式** | 需要描述数据结构、每次写 Prompt 或上传 CSV | 开箱即用，问就行 |
| **行业知识** | 通用知识，不懂零售术语 | Prompt 中预置零售 SQL 模板 + 行业术语解释 |
| **数据安全** | 数据上传到 OpenAI 云端 | **私有化部署**（Docker 一键部署）+ 数据不出企业 |
| **前端** | Web 通用界面 | **React 18 + TypeScript + Ant Design 5**（现代化企业 UI） |
| **输出格式** | 通用对话格式 | 结构化中文报告 + 可视化图表 + PDF 导出 + 🆕 企微/钉钉/飞书通知 |
| **部署方式** | 企业版 OpenAI Plugin（需配置） | **Docker 一键部署**（含预打包模型 + 种子数据） |
| **价格** | Enterprise 按用量计费 + 数据存储费 | 一次性部署（模型包预打包，无订阅费） |
| **差异化** | ChatGPT 给一个通用答案，我们提供 11 个 Agent 节点并行分析 + 根因诊断 + 可执行建议。更关键的是，我们的分析结果直接源自你的企业数据，不是通用知识库。 |
| **V4 区别** | OpenAI Enterprise Plugin 本质是"用户上传 + 调用我们的 Prompt 模板"，我们的核心是"LLM 自动编排 11 个 Agent 节点并行分析 + 自动生成图表 + 推送"。Plugin 不能编排复杂任务链路。 |

**面试回答模板**：
> "ChatGPT 就像一个聪明但不懂你公司业务的实习生。你需要先花 20 分钟给他解释你的数据库结构、行业术语、分析逻辑——而且每次提问都可能涉及不同字段。我们做的事就是这个实习生培训的自动化版本——它第一天就预设了零售业的数据库结构、SQL 模板和分析逻辑。你只要问，它就自动理解、自动编排、自动执行。"

## 相邻竞品（非直接竞争，但面试官可能会问）

### Tableau / Metabase

| 维度 | 分析 | 说明 |
|------|------|------|
| 为什么不是直接竞品 | Tableau 是可视化大屏工具，不做分析，只做展示 |
| 为什么面试官可能问 | 都涉及"数据可视化" |
| 回答 | "Tableau 把分析结果变成大屏展示。我们做分析本身，结果可以导出 PDF 或接入 Tableau 大屏。" |

### Metabase / ThoughtSpot

| 维度 | 分析 | 说明 |
|------|------|------|
| 为什么不是直接竞品 | ThoughtSpot 狆立数据源平台，需要和我们对接才能分析。如果没有数据源， ThoughtSpot 本身不做分析。 |
| 为什么面试官可能问 | 做面向分析师，不是我们这类 Agent 型产品 |
| 回答 | "ThoughtSpot 帮你把企业数据接入。我们适配器可以 5 分钟完成对接（自动发现 Schema（数据库结构）+ 映射）。你接入后，我们提供完整的 Agent 分析链路。" |

## 竞争壁垒分析

| 壁垒类型 | 我们有没有 | 说明 |
|----------|:--:|------|
| **技术壁垒** | 🟡 强 | **Multi-Agent 编排 + 图执行优化（单次执行 vs V3 流式 2 次调用）** + LLM 选型没有不可复制的技术秘密 |
| **数据壁垒** | ❌ 无 | 没有真实客户数据积累，这是最大短板 |
| **行业 Know-how** | 🟡 中等 | Prompt 中的零售 SQL 模板、业务知识是壁垒雏形，但需要真实场景打磨；V4 3 层 Schema 适配器（数据库结构适配器）让 30 分钟完成新客户接入 |
| **网络效应** | ❌ 无 | 单机部署，无网络效应。 |
| **切换成本** | 🟡 强 | 一旦嵌入企业工作流（周报 → 🆕 企微/钉钉/飞书 PDF 推送），切换成本会逐渐建立。 |
| **品牌/信任** | ❌ 无 | 最大短板——零售企业凭什么信任一个个人开源项目？ |
| **🆕 部署运维壁垒** | 🟡 强 | Docker 一键部署 + 预打包 BGE-M3 模型 + 自动迁移 + 离线镜像脚本 → 降低运维成本，提升交付速度。 |
| **🆕 合规性壁垒** | 🟡 强 | 全量审计日志（180 天保留）+ 数据不出企业 + RBAC 五级角色 → 满足企业合规审计要求。 |

**结论**：现阶段核心竞争力不是壁垒，而是**使用门槛的极致降低**+"**垂直场景的深度适配**。长期壁垒需要在真实客户场景中积累行业 Know-how 和数据飞轮。但我们的技术堆栈（LangGraph + DeepSeek + PostgreSQL + Redis + Ollama + React）和开箱即用的部署方案，足以撑起第一波种子客户。

## 如果我们进入市场，谁最可能反击？

| 对手 | 反击方式 | 我们的应对 |
|------|---------|-----------|
| 帆软 | 在 FineBI 里加一个自然语言查询入口 | **架构互补**：我们深度分析报告（根因+建议）是他们短期做不出来的。而且我们的 Agent 可以直接调用他们的 API 获取已看板数据进行分析。 |
| 观远 | 把异常检测结果接入 LLM 生成文字描述 | 我们走得更远——不只是描述异常，是诊断+处方+🆕 实时推送提醒。 |
| ChatGPT Enterprise | OpenAI 发布垂直行业插件 | **私有化部署 + 数据安全**是我们的护城河。通用 AI 无法隔离你的业务数据到企业网络环境。 |
| 开源 BI 工具 | 复制我们的 11 节点编排 + Prompt 模板 | 我们的架构（LangGraph + 结构化日志 + APM）难以在短期内复制。 |
