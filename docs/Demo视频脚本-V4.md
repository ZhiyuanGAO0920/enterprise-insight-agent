### 第六段：分析型问题——华东区销售下降根因（2:30-3:50）★ 核心段落

**画面**：

1. 逐字输入「最近30天华东区销售为什么下降了？分析具体原因并给出改进建议」
2. 点击发送
3. **镜头拉近进度条区域**，逐步骤展示：

   ```
   🧠 规划中 → Supervisor 激活 Sales、CRM、Finance
   📊 销售分析（正在执行 SQL 查询...）
   👥 CRM 分析（正在执行 SQL 查询...）    ← 三个并行
   💰 财务分析（正在执行 SQL 查询...）
   📊 整合结果（聚合 3 个 Agent 输出）
   📈 图表推荐（自动判断图表类型）
   📝 生成报告（流式逐字输出）
   ✅ 质量审核（4 维质检，不合格自动重写）
   📥 保存记录（pgvector 向量存储）
   ```

4. 报告流式输出过程中，鼠标指向实时更新的文字
5. 完整报告展示后 → **展开 📊 数据溯源面板** → 展示 SQL + 执行耗时
6. 滚动浏览完整报告 → 底部追问建议按钮（事件委托，data-* 属性传参）
7. 展示报告工具栏：📋 复制 / 🖨️ 打印 / ⬇️ Markdown / 📄 PDF

**旁白**：
> "现在来一个真正有难度的——华东区销售为什么下降。Supervisor 自动规划，激活 Sales、CRM、Finance 三个 Agent。注意看——它们并行执行，同时查数据库，互不等待。这是 LangGraph Send 实现的并行扇出。每个 Agent 有自己的工具：获取表结构、生成 SQL、执行查询。展开数据溯源面板——每一条 SQL、执行耗时、返回行数全部记录，数据 100% 可追溯。Report Agent 流式生成报告，你看到的每一个字都是实时推送到前端的。最关键的是 Reflection 质检——从数据一致性、逻辑严谨性、建议可操作性、问题覆盖完整性四个维度审核报告质量，不合格自动重写（最多 1 次）。底部工具栏支持复制、打印、Markdown 下载和 PDF 导出。"
