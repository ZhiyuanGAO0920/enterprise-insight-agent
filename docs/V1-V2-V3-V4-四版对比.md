## 一句话总结各版本

| 版本 | 定位 | 一句话 |
|------|------|--------|
| **V1** | 概念验证 | "验证自然语言 → SQL → 分析报告这条链路跑不跑得通" |
| **V2** | 生产就绪 | "让老板能在浏览器里用中文提问、拿到可信的分析报告" |
| **V3** | 体验质变 | "从能用 → 好用 + 让人信任 + 覆盖全业务域" |
| **V4** | 企业级平台 | "多租户隔离 + 全量审计 + 合规就绪 + 安全加固 + React 现代化前端" |

## Agent 体系对比

| 维度 | V1 | V2 | V3 | V4 |
|------|-----|-----|-----|-----|
| **编排框架** | 手动 Python 函数调用 | LangGraph StateGraph | LangGraph StateGraph | LangGraph StateGraph |
| **并行策略** | ❌ 顺序执行 | ✅ Send API 扇出 3 Agent | ✅ Send API 扇出 5 Agent | ✅ Send API 扇出 5 Agent |
| **领域 Agent** | 0（统一 Analyzer） | 3（Sales/CRM/Finance） | 5（+ Inventory/Supply Chain） | 5（同 V3） |
| **智能路由** | ❌ 固定流程 | ✅ Supervisor LLM 决策 | ✅ Supervisor LLM 决策（5 选多） | ✅ Supervisor LLM 决策 |
| **工具调用** | ❌ 硬编码 SQL 模板 | ✅ Function Calling (tool_choice) | ✅ Function Calling (tool_choice) | ✅ Function Calling（循环耗尽兜底） |
| **质检机制** | ✅ 简单 Reflection | ✅ 4 维结构化质检 | ✅ 4 维质检 + 条件重试 | ✅ 4 维质检 + retries 递增修复 |
| **错误隔离** | ❌ 一处失败全流程中断 | ✅ Agent 级 try/except 隔离 | ✅ Agent 级隔离 + 友好错误映射 | ✅ Agent 级隔离 + 降级错误报告 |
| **错误降级** | ❌ | ❌ | ❌ | ✅ 全 Agent 失败时生成诊断报告 |
| **上下文记忆** | ❌ 无 | ❌ 单轮 | ✅ 多轮对话（实体记忆+指代消解） | ✅ 多轮对话（+ 会话鉴权） |
| **RAG 增强** | ❌ | ❌ | ✅ 部分 Agent | ✅ 全部 5 个 Agent（补齐 inventory/sc） |
| **Prompt 管理** | ❌ 代码内硬编码 | ❌ Python 常量 | ✅ YAML 外部化 + 热重载 | ✅ YAML 外部化 + 热重载 |
| **流式执行** | ❌ | ✅ 8 步 SSE（2 次图执行） | ✅ 10 步 SSE（2 次图执行） | ✅ 10 步 SSE（**1 次**图执行，成本减半） |
